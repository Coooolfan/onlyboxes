# 持久执行租约账本与到期执行

`ExecutionLeaseLedger` 实现 BoxLite 独立租约守护器的账本、首次运行实例采纳、CAS 续租及到期执行视图。它使用[精确写入者身份与停止原语](sandbox-snapshot-runtime.md#独立停止原语)，不删除 guest 磁盘，也不调用 SDK 启动、停止或删除 API。调用方负责在独立于 Worker 的进程及独立于磁盘写入的执行线程中持续调用 `enforce`。

当前原生实验使用自有守护子进程，生产控制通道、监督、受控启动前授权及 Worker 注册尚未完成。`sandbox_persistence` 仍不宣告；此组件不能单独作为完整持久化能力启用。

## 状态与归属

专用绝对目录必须属于当前用户，权限为 `700`；`guard.lock`、`owner.json` 与 `leases.json` 为私有、单硬链接普通文件，权限为 `600`。目录不能作为沙箱挂载或归档缓存目录。生产集成还必须校验它与 SDK home、生命周期 journal 的分离关系。

`owner.json` 固定 Worker ID、宿主身份、随机 store ID，以及目录的规范路径、设备号和 inode。`leases.json` 携带相同 store ID，最多保留 16,384 条记录，整个 JSON 不超过 64 MiB。记录包含 scope、不可变 Box ID、generation、revision、绝对到期时间及精确宿主写入者身份，不包含 Console secret、恢复规格环境变量或对象存储授权。

文件通过私有临时文件、文件 sync、原子替换及父目录 sync 提交。失去账本但保留 owner、复制或替换目录、不同 Worker/host、损坏或重定向的文件都拒绝打开。识别到的中断临时文件仅在完整归属与账本校验后清理，未知文件保持不可用。打开期间，控制操作还会核对目录、owner 及独占锁文件身份；原路径被替换时不能跟随到新存储继续写入。

`open` 用于首次受控建立存储；已绑定 Worker 必须使用 journal 中固定的 store ID 调用 `open_bound`。绑定重开时，整个目录或 owner 丢失也会拒绝，不初始化空账本。生产启动仍须把 store ID、目录和守护进程身份与生命周期 journal 配对，不能在重启时重新读取一个新 ID 后替代原绑定。

## 确认与时钟

首次采纳仅接受已运行、精确身份一致的原实例，generation 和初始 revision 均为 `1`。确认前后均重新核对实际写入者。相同已接受请求可重放；更换 scope、generation、进程、Box ID，或为同一 scope 建立另一个 ID 均拒绝。已撤销、过期或重开账本中的旧记录不能通过 `adopt` 恢复执行权。

续租携带 expected revision 和完整目标回执。它保持同一身份，不缩短到期时间，成功后 revision 加一；丢失应答可重放同一已接受结果。缺失记录不能通过续租创建。多个调用竞争相同 revision 时，只能确认其中一个不同的目标结果。

每个运行租约同时保存绝对到期时间和内存中的单调时钟期限，任一到期都会关闭执行权。续租通过原单调期限加上本次明确授权的延长量得到新期限，不以回退后的墙钟重新计算一个更长期限。到期观察是不可逆的，即使墙钟随后回退也不重新开放。

重开账本时无法证明旧单调时钟连续性，因此全部历史记录在新进程的执行视图中撤销，包括绝对时间仍未到期的记录。状态回执中的 `revoked` 包含这一有效状态；revision 记录已接受的持久化 CAS，不会因轮询或重启自行增长。撤销状态不通过修改磁盘上的 lease 时间来延长或刷新旧 grant。

## 磁盘阻塞与到期动作

磁盘状态锁和到期视图的锁分离。首次采纳在不确定写入前登记原实例为停止目标；任何不确定写入都会关闭账本控制入口，并使所有已知目标进入停止路径，包括未得到成功回执的首个实例。

续租写盘期间，旧期限继续有效。新状态持久化后，只有原期限仍有效、实例仍匹配且没有发生停止决定，才原子发布新期限并确认。写入拖过旧期限时，到期执行可以先停止原进程；磁盘后来写入了更远的时间也不能返回续租成功。持久化意图不能代替控制回执。

到期扫描不读取账本目录，不取得磁盘状态锁，也不等待 sync。每次最多投递 64 个精确停止请求，失败目标继续保留。停止投递与期限发布使用同一实例锁，旧扫描不能在续租已发布后再误停实例。调用频率、队列积压和内核可响应性共同影响停止延迟，这个上限不是生产停止时限承诺。停止请求成功仍须由生命周期协议另行核实写入者退出；不能只凭墙钟或 Worker 不可达就转移所有权。

## 验证与剩余接入

```sh
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo run --locked --example boxlite_home_guard_smoke
```

无 VM 测试覆盖私有权限、独占锁、目录/store ID 绑定、账本丢失、路径/锁文件替换、损坏和链接拒绝，以及墙钟回退不可复活。macOS 自有进程测试覆盖采纳/续租重放、CAS 竞争、身份变更、缺失及过期拒绝、重开撤销、不确定首次写入、慢续租时的独立到期停止。慢写入实验在持久化线程阻塞期间驱动到期执行，确认旧期限停止不等待该线程。

原生实验先确认账本采纳及续租，再 SIGKILL SDK 宿主。独立守护子进程持续运行；新 SDK 进程验证相同 VM PID、数据及仍持续增长的后台写入，旧期限后实例仍活跃，新期限到期后确认写入者退出及 guest 磁盘保留。随后才由 SDK 完成授权清理和残留恢复。该实验不等同于实际 Worker `Run`、Linux BoxLite VM、受监督服务、真实 Console/S3 或跨机器验收。

尚需实现守护器私有控制协议、关闭与监督、受控 start/import 的任务所有权、回滚时的明确重新授权、原生清理后释放记录，以及生产配置、采纳/续租/重连门禁和 Hello 注册。当前接口只采纳已运行实例；它不会授权新的 PID，也不会凭停止或过期自行释放 scope 供第二个可写实例接管。运行时的 `Drop` 仅释放账本锁，不能代替服务级停止、守护器重启或到期执行。
