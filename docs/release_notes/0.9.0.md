## feat
* Add `worker-bridge-e2b`, an execution node that bridges the console to remote E2B sandboxes and declares `echo`, `pythonExec`, `terminalExec`, and `terminalResource` over the existing worker registry stream https://github.com/Coooolfan/onlyboxes/pull/14 https://github.com/Coooolfan/onlyboxes/commit/3d9529a
* Export terminal files straight from the E2B sandbox to the console presigned URL through `WORKER_TERMINAL_EXPORT_MODE=sandbox`, keeping file bytes off the worker; `worker` mode still streams through the worker https://github.com/Coooolfan/onlyboxes/commit/079a61b
* Highlight code blocks in website docs with build-time Shiki tokens and separate light/dark palettes https://github.com/Coooolfan/onlyboxes/commit/107f82c

## fix
* Stop interrupted E2B commands by tagging each `process.Process/Start` call and killing the process when the stream ends early, so cancelled commands leave no runaway process in the sandbox https://github.com/Coooolfan/onlyboxes/commit/5a0afc3
* Reject expired terminal sessions with `session_not_found` and destroy the stale sandbox instead of reusing a dead lease https://github.com/Coooolfan/onlyboxes/commit/d2ef5e9
* Serialize E2B lease updates so concurrent commands in one session cannot shorten or race the sandbox timeout https://github.com/Coooolfan/onlyboxes/commit/527496c
* Apply `WORKER_E2B_REQUEST_TIMEOUT_SEC` to envd dial, TLS handshake, and response headers, and let established streams follow the console command deadline https://github.com/Coooolfan/onlyboxes/commit/b10488b https://github.com/Coooolfan/onlyboxes/commit/99ec500
